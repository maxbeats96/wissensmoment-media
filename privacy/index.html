Datenschutzerklärung

Stand: 27.09.2026

Der WissensMoment Publisher ist ein privat betriebenes Werkzeug, das ausschließlich vom Betreiber des TikTok-Accounts „wissensmoment“ genutzt wird.

Welche Daten verarbeitet werden

  • Nach der Anmeldung über „Login with TikTok“ erhält das Tool ein Zugriffstoken für den eigenen Account. Es wird verschlüsselt als Geheimnis in GitHub Actions gespeichert und nur verwendet, um Karussell-Entwürfe an die TikTok-Inbox zu senden.
  • Abgefragt werden nur die Basisangaben des Accounts (Scope user.info.basic) und die Upload-Berechtigung (Scope video.upload).
  • Es werden keine Daten anderer TikTok-Nutzer erhoben, keine Tracking-Cookies gesetzt und keine Daten an Dritte verkauft oder weitergegeben.
  • Die Karussell-Bilder werden öffentlich auf dieser Website bereitgestellt, damit TikTok sie abrufen kann. Sie enthalten keine personenbezogenen Daten.

Löschung

Der Zugriff kann jederzeit in den TikTok-Einstellungen unter „Sicherheit → Apps und Dienste“ widerrufen werden. Gespeicherte Tokens werden dann ungültig und gelöscht.

Kontakt

Bei Fragen per Direktnachricht an den TikTok- oder Instagram-Account „wissensmoment“.

Privacy Policy (English)

WissensMoment Publisher is a private tool used only by the owner of the TikTok account “wissensmoment”. After “Login with TikTok” it stores an access token as an encrypted GitHub Actions secret and uses it solely to send carousel drafts to that account's TikTok inbox (scopes user.info.basic, video.upload). No data of other users is collected, no tracking cookies are used and no data is sold or shared. Carousel images are hosted publicly on this site so TikTok can fetch them; they contain no personal data. Access can be revoked at any time in TikTok settings.
